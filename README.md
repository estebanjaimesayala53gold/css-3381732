# Catálogo Web - ADSO SENA

Proyecto práctico del tecnólogo en Análisis y Desarrollo de Software (ADSO) del SENA.

## ¿Qué hacemos aquí?

Creamos la página web de un catálogo de dulces desde cero, organizando los estilos con variables para que sea fácil cambiar los colores y las fuentes, usando Google Fonts y ordenando las imágenes de los productos.

## Lo que utilizamos:

- **HTML5:** Para la estructura de la página y las tarjetas de los productos.
- **CSS3:** Para dar diseño, usar variables (`:root`) y acomodar las cosas con Flexbox.
- **Google Fonts:** Para la tipografía oficial (Inter).
- **Git y GitHub:** Para guardar las versiones del código y subirlo al repositorio del equipo.
